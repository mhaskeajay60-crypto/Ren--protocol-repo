# Third-Party Notices

## unpdf

The approval-first local PDF chapter importer uses the `unpdf` package to parse selected PDF files inside the browser. Its browser-capable serverless PDF.js bundle avoids a separate worker request. The imported file is not uploaded for this local extraction path.

- Project: [unjs/unpdf](https://github.com/unjs/unpdf)
- License: MIT
- Purpose in The Ren Protocol: browser-local PDF text extraction for author-approved chapter previews.
