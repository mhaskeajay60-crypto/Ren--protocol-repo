# Pocket Story Console Research Notes

The Pocket Story Console redesign uses patterns, not copied layouts, from the references below. All interface copy, artwork, and application behavior remain original to The Ren Protocol.

## Progressive creation

[Nielsen Norman Group’s explanation of progressive disclosure](https://www.nngroup.com/videos/progressive-disclosure/) states that secondary options should be deferred to a subsidiary screen so primary choices remain in focus. This supports the approved replacement of long character, arc, scene, and place forms with small first steps, optional details, and a final preview.

## Connected worldbuilding

[LegendKeeper](https://www.legendkeeper.com/) demonstrates category-based worldbuilding with connected lore, linked maps/pins, boards, and timelines. The relevant lesson for The Ren Protocol is not to copy the product, but to keep a visual destination for each kind of world detail and let authors open a focused record page rather than browse repeated generic cards.

## Mobile game information architecture

[Game UI Database](https://www.gameuidatabase.com/) catalogs mobile and game interface patterns including codex/journal, map, objectives, player statistics, character editing, and compact navigation screens. The relevant design direction is a small number of high-frequency destinations, strong action labels, compact empty states, and detail screens opened only when needed.

## Applied decisions

The approved rebuild therefore uses a five-destination mobile dock, a concise Writer Pulse, one planning lane at a time, fast Text/File/Link Vault capture, category-specific Masterbook destinations, and progressive author builders. Browser-local data and protected private-team canon remain separate and are not sent or changed by the redesign.
