# Chapter, PDF, and Feature Access Findings

## Desktop

The refreshed desktop Write workspace now presents **Import chapter PDF**, **My PDF imports**, and **Possible Masterbook updates** directly beside the chapter heading. The top bar contains a visible **Tools** entry that opens the grouped Feature Map. The chapter list and manuscript remain available together, preserving the desktop writing workflow.

## Phone

At 375 pixels, the chapter screen keeps the fixed five-destination Pocket Story Console dock, a compact top More action, and an in-app Back control. The direct PDF and Masterbook review actions stack above the chapter list rather than being hidden in the old More writing-tools disclosure. The narrow layout remains readable without horizontal overflow; the direct PDF controls should receive stronger button treatment in the final style pass so they look as tappable as the Masterbook review action.

## Privacy Boundary

Possible Masterbook updates discovers only pre-existing Masterbook record names from locally saved chapter text. It offers a private reference link only after author approval. It does not generate a fact, edit a Masterbook record, submit a group proposal, send chapter text, or make canon automatically.
